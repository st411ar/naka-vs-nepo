# Naka vs Nepo

Статический пользовательский сайт для просмотра шахматной статистики из Chess API.

## Возможности версии 1.0.0

- хронология результатов по турнирам и годам;
- все турниры изначально свернуты;
- сравнение двух выбранных игроков;
- Ян (`nepo`) и Хикару (`naka`) выбраны по умолчанию;
- подсчет участий, мест, подиумов и лучшего результата;
- для кубковых турниров подиумы не считаются;
- кубковые результаты поддерживают значения `1`, `2`, `1/2 финала`, `1/4 финала` и далее;
- адаптивный интерфейс для компьютера и телефона.

## Размещение

Сайт не требует сборки. Все файлы из архива нужно положить в корень репозитория `naka-vs-nepo` и включить GitHub Pages для ветки `main`, папка `/ (root)`.

## Определение кубкового турнира

Турнир считается кубковым, если его русское название содержит слово `кубок` или среди результатов найдено значение формата `1/N финала`.
